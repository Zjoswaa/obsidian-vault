Het analyseren van hoogtekaartdata is cruciaal om de stevigheid van de duinen in Nederland te behouden. Het lokaal analyseren van deze data kost veel tijd, een oplossing is het gebruik maken van cloud computing, hiermee kan de data op externe locaties worden verwerkt. De hoofdvraag van dit onderzoek gaat in op de manier hoe cloud computing kan worden gebruikt voor de analyze hoogtekaartdata en welke voor- en nadelen dit met zich meebrengt.

Het antwoord op deze hoofdvraag is verkregen door middel van een literatuuronderzoek.
Door middel van dit onderzoek is informatie verzameld over de verschillende toepassingen van cloud computing op hoogtekaartdata. De drie clouddiensten die beschikbaar zijn, zijn SaaS, PaaS en IaaS. Waarbij IaaS het meest geschikt is voor het verwerken van hoogtekaartdata vanwege de flexibiliteit, veiligheid en lage kosten.
Er zijn 4 mogelijke Clouddiensten die een goede oplossing kunnen bieden, welke de beste optie biedt, hangt af van de manier waarop de data moet worden verwerkt. Wel kan worden gesteld dat het gebruik van cloud computing een betere oplossing biedt dan het lokaal verwerken van de data.
Er wordt aanbevolen om gebruik te maken van Public Cloud omdat er niet veel significante veiligheidsrisico's zijn en dit goedkoper is. Ook wordt aanbevolen om gebruik te maken van IaaS omdat deze het beste schaalbaar is en vanwege de schaarse aan gestandaardiseerde software voor de verwerking van hoogtekaartdata. Ook wordt het gebruik van een serverless clouddienst aangeraden, als de omzetting hiernaar lastig is, biedt het gebruik van containers de beste oplossing, als dit ook niet mogelijk is, is het gebruik van een VPS het beste alternatief.
Een suggestie voor vervolgonderzoek is om te kijken naar hoe de dataverwerking van hoogtekaartdata effectief omgezet kan worden naar cloud functions zodat er beter gebruik gemaakt kan worden van een serverless oplossing.

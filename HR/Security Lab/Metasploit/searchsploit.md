Onderdeel van [[Metasploit]].

Geeft een lijst van exploits, en de `ID` ervan.
```bash
searchsploit <term>
```
```bash
searchsploit hikvision
```
```bash
searchsploit -x <ID>
```
```bash
searchsploit -m <ID>
```
- `-x` - Examineer (open) de exploit. Dit laat je de informatie van deze exploit zien.
- `-m` - Mirror (kopiëer) de exploit naar de huidige working directory.

Er zijn veel tools beschikbaar voor penetration testing met AI, van "normale" LLM's tot aan agents en autonome systemen.
Voordelen van AI pentesten:
- Snellere detectie van zwakheden.
- Security testing.
- Aanval simulaties.
- Minder false positives.
Verschillende modellen presteren op andere manieren binnen cybersecurity.
Zelfs verschillende parameters binnen hetzelfde model kunnen verschillende resultaten geven.
# LLM naar Agent
- LLM = Large Language Model, voorspelt tokens per karakter, zin, paragraaf, gebaseerd op een enkele input.
- Agent = LLM die een bepaalde rol aanneemt en specifieke skills heeft. Hij kan resultaten interpreteren en vervolgens de workflow voortzetten.
Een aantal features van een AI agent zijn:
- Toolpermissies.
- Controlepunten coor menselijke goedkeuring.
- Context- en statemanagement.
# Pentesting met AI
Ga er niet van uit dat de agent weet wat je wilt.
- Verplichte versus optionele acties.
- Kwaliteitsnormen.
- Outputformaten.

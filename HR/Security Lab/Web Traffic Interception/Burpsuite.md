Is een [[Web Traffic Interception|web traffic interception]] tool.

Sommige features zijn betaald. Community edition mist sommige features.

Onder `Proxy` > `Proxy settings` kan je de listening IP en port aangeven. Hier kan je ook een certificaat generere die je in je browser kan installeren.

Wanneer je dan Intercept aan zet, vangt Burp alle requests, voordat hij ze doorstuurt.

Het verschil met [[mitmproxy]] is dat Burpsuite de requests niet eerst door laat gaan, en je ze later laat "Replayen", maar de initiele request uberhaubt niet stuurt en je het eerst laat wijzigen.

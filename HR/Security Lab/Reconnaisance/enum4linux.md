Voorbeeld van active [[Reconnaisance|reconnaisance]].

Tool om informatie over een systeem te verkrijgen zoals users, machines, password policy, groups.
```bash
enum4linux <IP>
```
- `-a` - Zoek alle informatie die je kan vinden.
- `-U` - Zoek de users.
- `-M` - Zoek machines.
- `-P` - Zoek password policy.

- A collection of information that is organized so that it can be easily accessed, managed and updated.
- A table consist of records and fields
	- Records = rows
	- Fields = columns
## Flat-file database
- A database with one table is called a **flat-file database**.
- ==**Primary key**==: A field that is unique for every record.
## Relational database
- A relational database has **multiple tables** which are **linked** through their key fields.
- A ==**foreign key**== is a field in a table that is a **primary key** in another table.
## Querying
- A query is written in [[SQL]].
- Allows the user to use a chain of commands to select a portion of a database.
## Database management systems
- Allows users to filter a table based on certain parameters and restrictions. The engine will create a request to the database. A request like that is called a **query**.
- The system can **add**, **read**, **modify**, and **delete** data.
- Examples of database management systems:
	- Oracle
	- MySQL
	- PostgreSQL
	- SQLite
